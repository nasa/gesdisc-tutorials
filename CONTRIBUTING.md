# Contributing Steps

***Thanks for contributing to the `gesdisc-tutorials` GitHub repository!***

Please follow these instructions to add your changes in a pull request

1. In the branch merge dropdowns, make sure to select `dev` ← `your-branch`. **Pull requests will be disapproved if `main` ← `your-branch` is selected**.  
2. Click "Create Pull Request".
3. Add the appropriate **labels/tags** to your PR using the **Labels** option on the right side of the pull request page.
4. Request **2 reviews** from other contributors.
5. After 2 approvals, your PR can be merged into `dev`.
