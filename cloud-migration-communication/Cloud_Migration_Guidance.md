# GES DISC Cloud Migration Guidance

As the Earth Science Data Systems (ESDS) Program moves toward a consolidated Earthdata entity through its web presence and data access through the Earthdata Cloud, GES DISC is undergoing several changes in the coming months that users and data providers should be aware of. This document will be updated as more information becomes available. For any questions or help finding data, please reach out to gsfc-dl-help-disc@mail.nasa.gov or visit the Earthdata Forum.

## For all GES DISC data users

1. Migration to the Earthdata website
GES DISC will be migrating the GES DISC website to the Earthdata website. While both sites will remain active during the transition phase (from May 2026 to November 2026), all traffic will be redirected to the Earthdata website after November. This guide will help you navigate the new Earthdata website. To learn more about ESDS’s Web Unification Project, please visit https://www.earthdata.nasa.gov/about/web-unification-project. 

2. Discontinuation of on-premises data services
GES DISC will be discontinuing several data access services and tools that reside on our on-premises servers. 
OPeNDAP: GES DISC data collections with OPeNDAP access will be enabled in the OPeNDAP in the Cloud. As collections are fully enabled in OPeNDAP in the Cloud, the on-premises OPeNDAP access will discontinue. GES DISC is using a phased approach to this transition where all on-premises OPeNDAP access will be inaccessible between now and the end of September. Visit our guide to learn more about the OPeNDAP in the Cloud and step-by-step instructions on transitioning your workflows for continued access. 
GES DISC Level 2 Subsetter: GES DISC Level 2 data collections with GES DISC Level 2 Subsetter access will be enabled in the Earthdata Enterprise Subsetter. When collections are fully enabled in the Earthdata Enterprise Subsetter, the GES DISC Level 2 Subsetter will discontinue, no earlier than June 30, 2026. The subsetting interface through the GES DISC website will be accessible through November, now through the Data Access button and using the Earthdata Enterprise Subsetter. API users will need to switch to the Harmony API. See our tutorials for more information on using the Earthdata Enterprise Subsetter interface and Harmony API with Python.
GES DISC Level 3 and 4 Regridder and Subsetter Service (L34RS): GES DISC Level 3 and 4 data collections with L34RS access will be enabled in the Harmony OPeNDAP Subsetting Service (HOSS) and the Harmony OPeNDAP URL Service (HOUS). When collections are fully enabled in HOSS, L34RS will discontinue, no earlier than July 31, 2026. HOSS does not support regridding services, but an alternative is Climate Data Operators (CDO). The subsetting interface through the GES DISC website will be accessible through November, now through the Data Access button and using HOSS. API users will need to switch to the Harmony API. The API is required for dimension subsetting services. See our tutorial on using the Harmony API to subset data using Python.
THREDDS Data Server (TDS): The THREDDS Data Server (TDS) will be discontinued no earlier than June 30, 2026. An alternative to TDS is virtualized data stores, and we are working on offering those for some popular data collections over a limited time period using VirtualiZarr. Another alternative for aggregation is netCDF Operator (NCO). For more information on using NCO for aggregation, see our tutorial.
AIRS Level 1 and 2 Subsetter: The AIRS Level 1 and Level 2 Subsetter will be discontinued no earlier than June 12, 2026. Once all of the collections are enabled in OPeNDAP in the Cloud, dimension-based channel subsetting and variable subsetting will be available. See our tutorial on using OPeNDAP in the Cloud and Python to subset AIRS Level 1 and Level 2 data.
Previously available services that have been discontinued: GrADS Data Server (GDS), AIRS Near-Real-Time (NRT) Viewer tool; Hydrology Data Rods service; NASA Level 2 Data Quality Visualization Service (DQViz); Open Geospatial Consortium (OGC) Web Map Service (WMS) for AIRS, TRMM, and OMI data; Multi-sensor Aerosol Products Sampling System (MAPSS) tool. 
Giovanni: Giovanni will continue to exist in its current form until further notice, but users are encouraged to try our Giovanni in the Cloud area-averaged time series and time-averaged mapping services and Hydrology Time Series Viewer.

3. Changes to HTTPS data access
HTTPS access to data on our on-premises servers (https://<server>.gesdisc.eosdis.nasa.gov/) will no longer be available by September 30, 2026. GES DISC is using a phased approach to this transition where direct access to our on-premises servers will be disabled between now and the end of September. Scripts used to construct URLs for data/OPeNDAP from these systems will cease to function once public access is disabled. However, data will continue to be available for HTTPS download from the Earthdata Cloud (data.gesdisc.earthdata.nasa.gov/data/*), though some functionality - notably recursive download of entire directories via curl/wget - will not be available. Instead, lists of granule URLs will need to be compiled via query to NASA’s Common Metadata Repository (CMR). In addition to the CMR API, Earthdata Search provides an interface to finding and downloading granules. See our tutorial for accessing GES DISC data via Earthdata Cloud using Python.

## For GES DISC data providers

1. Data subscriptions
Certain users or groups that access restricted data through a subscription will not see an interruption in access to forward stream data. However, data will only be available for a short period of time, at which time data will “roll off” and will be stored in the cloud. If you anticipate needing access to historical data through your subscription, please contact GES DISC as soon as possible. 

2. Future data ingest interfaces
By September 30, 2026, our on-premises data archives will only maintain a “rolling” archive of data, with the Earthdata Cloud being the primary host of all GES DISC data. This means that only a small amount of forward stream data will pass-through our on-premises systems to accommodate existing data ingest interfaces. As noted in item 3, this data will not be accessible publicly. After October 1, 2026, GES DISC will begin converting all existing data ingest interfaces to deliver direct to our Earthdata Cloud. All new data products and new interfaces must be configured to ingest directly to cloud.
