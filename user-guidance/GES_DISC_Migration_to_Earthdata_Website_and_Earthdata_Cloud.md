# GES DISC Migration to Earthdata Website and Earthdata Cloud 
Originally published: May 11, 2026

Last updated: May 11, 2026 (rev 1)

As the Earth Science Data Systems (ESDS) Program moves toward a consolidated Earthdata entity through its web presence and data access through the Earthdata Cloud, GES DISC is undergoing several changes in the coming months that users and data providers should be aware of. This document will be updated as more information becomes available. For any questions or help finding data, please visit the [Earthdata Forum](https://forum.earthdata.nasa.gov/), or reach out to gsfc-dl-help-disc@mail.nasa.gov before November 2026.

## For all GES DISC data users

### Migration to the Earthdata website
Information in the [GES DISC website](https://disc.gsfc.nasa.gov) will be migrated to the [Earthdata website](https://earthdata.nasa.gov). While both sites will remain active during the transition phase (from May 2026 to November 2026), all traffic will be redirected to the Earthdata website after November 2026. This [guide](https://disc.gsfc.nasa.gov/information/documents?keywords=migration&title=Migration%20to%20Earthdata) will help you navigate the new Earthdata website. To learn more about ESDS’s Web Unification Project, please visit https://www.earthdata.nasa.gov/about/web-unification-project. 

### Updates to Giovanni Service
[Giovanni](https://giovanni.gsfc.nasa.gov/giovanni/) will continue to exist in its current form until further notice, but users are encouraged to try our [Giovanni in the Cloud area-averaged time series and time-averaged mapping services](https://disc.gsfc.nasa.gov/information/howto?keywords=giovanni&title=How%20to%20Access%20the%20Giovanni%20Area-Averaged%20Time%20Series%20and%20Time-Averaged%20Mapping%20Service%20Using%20Python), and point time-series using the [Hydrology Time Series Viewer](https://disc.gsfc.nasa.gov/information/tools?title=Hydrology%20Time%20Series).

### Discontinuation of on-premises data services
GES DISC is migrating data access and services to Earthdata Cloud. In the process, based on usage history, several data access services and tools that reside on our on-premises servers will be discontinued. 

#### OPeNDAP: 
GES DISC data collections with [OPeNDAP](https://www.opendap.org/documentation/) access will be [enabled in the Earthdata Cloud](https://opendap.earthdata.nasa.gov/). As collections are fully enabled in OPeNDAP in the Cloud, the on-premises OPeNDAP access will discontinue. GES DISC is using a phased approach to this transition where all on-premises OPeNDAP access will become inaccessible between now and the end of September 2026. Visit our [guide](https://disc.gsfc.nasa.gov/information/howto?keywords=OPeNDAP%20in%20the%20Cloud&title=OPeNDAP%20In%20The%20Cloud) to learn more about the OPeNDAP in the Cloud and step-by-step instructions on transitioning your workflows for continued access.

####  GES DISC Level 2 Subsetter:
GES DISC Level 2 data collections with [GES DISC Level 2 Subsetter](https://disc.gsfc.nasa.gov/information/howto?keywords=level%202%20subsetter&title=How%20to%20Subset%20Level-2%20Data) access will be transitioned to the [Earthdata Enterprise Subsetter](https://disc.gsfc.nasa.gov/information/howto?keywords=level%202&title=GES%20DISC%20Level%202%20Subsetter%20Replaced%20with%20Enterprise%20Level%202%20Subsetter). When collections are fully enabled in the Earthdata Enterprise Subsetter, the GES DISC Level 2 Subsetter will discontinue, no earlier than June 30, 2026. The subsetting interface through the GES DISC website will be accessible through November, now through the Data Access button and using the Earthdata Enterprise Subsetter. API users will need to switch to the [Harmony API](https://harmony.earthdata.nasa.gov/docs#using-the-service-apis). See our tutorials for more information on using the Earthdata Enterprise Subsetter [interface](https://disc.gsfc.nasa.gov/information/howto?title=How%20to%20Subset%20Level%202%20Data%20with%20the%20Earthdata%20Enterprise%20Subsetter) and [Harmony API with Python](https://disc.gsfc.nasa.gov/information/howto?title=How%20to%20Subset%20and%20Download%20Level%202,%203,%20and%204%20GES%20DISC%20Data%20Using%20Python).

#### GES DISC Level 3 and 4 Regridder and Subsetter Service (L34RS):
GES DISC Level 3 and 4 data collections with [GES DISC Level 3 and 4 Regridder and Subsetter Service](https://disc.gsfc.nasa.gov/information/service-release?title=GES%20DISC%20Level%203%20and%204%20Regridder%20and%20Subsetter) (L34RS) access will be enabled in the [Harmony OPeNDAP Subsetting Service (HOSS)](https://github.com/nasa/harmony-opendap-subsetter) and the Harmony OPeNDAP URL Service. When collections are fully enabled in HOSS, L34RS will discontinue, no earlier than July 31, 2026. HOSS does not support regridding services, but an alternative that users can run offline is [Climate Data Operators (CDO)](https://www.climate-cryosphere.org/wiki/index.php/Regridding_with_CDO). The subsetting interface through the GES DISC website will be accessible through November, now through the Data Access button and using HOSS. API users will need to switch to the Harmony API. The API is required for dimension subsetting services. See our tutorial on using the [Harmony API to subset data using Python](https://disc.gsfc.nasa.gov/information/howto?title=How%20to%20Subset%20and%20Download%20Level%202,%203,%20and%204%20GES%20DISC%20Data%20Using%20Python).

#### THREDDS Data Server (TDS):
The [THREDDS Data Server (TDS)](https://www.unidata.ucar.edu/software/tds) will be discontinued no earlier than June 30, 2026. An alternative to TDS is virtualized data stores, and we are working on offering those for some popular data collections over a limited time period using [VirtualiZarr](https://virtualizarr.readthedocs.io/). Another alternative for aggregation is [netCDF Operator (NCO)](https://github.com/nco/nco). For more information on using NCO for aggregation, see our [tutorial](https://disc.gsfc.nasa.gov/information/howto?keywords=aggregation&title=How%20to%20Concatenate%20the%20Time%20Dimension%20of%20netCDF%20Files%20with%20NCO).

#### AIRS Level 1 and 2 Subsetter:
The AIRS Level 1 and Level 2 Subsetter will be discontinued no earlier than June 12, 2026. Once all of the collections are enabled in OPeNDAP in the Cloud, dimension-based channel subsetting and variable subsetting will be available. See our [tutorial](https://github.com/nasa/gesdisc-tutorials/blob/main/notebooks/How_to_Subset_L1_L2_AIRS_Using_OPeNDAP_and_Python.ipynb) on using OPeNDAP in the Cloud and Python to subset AIRS Level 1 and Level 2 data.

### Changes to HTTPS data access
HTTPS access to data on our on-premises servers (`https://\<server\>.gesdisc.eosdis.nasa.gov/...`) will no longer be available by September 30, 2026. GES DISC is using a phased approach to this transition where direct access to our on-premises servers will be disabled between now and the end of September. Scripts used to construct URLs for data or OPeNDAP requests from these systems will cease to function once public access is disabled. However, data will continue to be available for HTTPS download free of charge from the Earthdata Cloud (URLs starting with `https://data.gesdisc.earthdata.nasa.gov/...`), though some functionality - notably recursive download of entire directories via wget/curl - will not be available. Instead, lists of granule URLs will need to be compiled via query to NASA’s [Common Metadata Repository (CMR)](https://www.earthdata.nasa.gov/about/esdis/eosdis/cmr). 

In addition to the [CMR API](https://cmr.earthdata.nasa.gov/search/site/docs/search/api.html), [Earthdata Search](https://search.earthdata.nasa.gov/) provides an interface to finding and downloading granules. The community developed [Earthaccess Python Package](https://github.com/earthaccess-dev/earthaccess) is a recommended tool for finding and downloading data from EarthData from within Python. See our [tutorial](https://github.com/nasa/gesdisc-tutorials/blob/main/notebooks/How_to_Access_GES_DISC_Data_Using_Python.ipynb) for other methods of accessing GES DISC data via Earthdata Cloud using Python. A browsable listing of data files, similar to the old HTTPS interface, is available at [Earthdata  Provider Holdings Directory](https://cmr.earthdata.nasa.gov/search/site/collections/directory/eosdis) - though it should be noted that recursive wget/curl will NOT work on this interface.

For users with access to AWS resources in the `us-west-2` region, direct S3 access to data is available. See [this tutorial](https://nasa-openscapes.github.io/earthdata-cloud-cookbook/how-tos/access-data/access-cloud-python.html) for an example of direct S3 access using the Earthaccess Python library. Direct S3 URLs can be found in CMR, both via [Earthdata Search](https://search.earthdata.nasa.gov/) and API queries.

## For GES DISC data providers

### Future data ingest interfaces
By September 30, 2026, our on-premises data archives will only maintain a “rolling” archive of data, serving as a pass-through to maintain existing data interfaces with the Earthdata Cloud becoming the primary host of all GES DISC data. This means that only a small amount of newly-ingested data will pass-through our on-premises systems. Data will not be accessible publicly via the on-premises server, only via Earthdata Cloud/Cumulus. After October 1, 2026, GES DISC will begin a strong focus on converting all existing data ingest interfaces to deliver directly to our Earthdata Cloud. Existing data providers should expect communication from GES DISC when the time comes to migrate their respective interface. All new data products and new interfaces must be configured to ingest directly to cloud. Please feel free to reach out to GES DISC if you have any questions or concerns.

### Data subscriptions
Certain users or groups that access newly-ingested data via a subscription will not see an interruption to those subscriptions. However, data will only be available on-premises for a short period of time, after which time data will “roll off” our archive and will only be accessible from the cloud. If you anticipate needing access to historical data through your subscription (e.g. via the MRI tool), please contact GES DISC as soon as possible.
